# Front panel

The 3D-printed panel that carries the WT32-SC01 Plus, the MSGEQ7 protoboard, the pot and the jack.

| File | What it is |
|---|---|
| `rackglow-panel.f3d` | Fusion 360 source — the editable original |

`.f3d` opens in Fusion 360 only. A STEP export (for every other CAD package) and printable STLs
are still to come, along with print settings; until then the source is here so the design is not
stuck on one machine.
